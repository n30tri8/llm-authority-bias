# Who are LLMs’ Cognitive Authorities? A Case Study

This project is a fork of the original "Who are LLMs’ Cognitive Authorities?" study. It extends the initial research by introducing several key enhancements:
- **Multilingual Benchmarking**: We have added capabilities to assess authority bias across different languages.
- **Expanded Model Support**: New models have been integrated to broaden the scope of bias detection.
- **MMLU Benchmark Integration**: The MMLU benchmark has been incorporated to specifically investigate gender bias.

The primary focus of this work is to analyze gender bias in Large Language Models, particularly from a third-person perspective.

# Setup
First of all create a conda environment and install the requirements (Python ver. == 3.10)
```bash
conda create --name llm_authority_bias python=3.8
pip install -r requirements.txt
```
Then, create a ```keys.json``` file following the ```keys_template.json``` format.

# Running the experiments
The experiments are run in a three-step process:
1.  **`extract-known`**: Identify which questions from a benchmark the model already knows the answer to.
2.  **`measure`**: Measure the authority bias on the questions the model knows.
3.  **`summarize`**: Summarize the results of the experiments.

## 1. Extract known questions
This command filters a question bank to identify questions a model can answer correctly without any external influence.

```bash
python cli.py extract-known --qbank <path-to-your-local-repo>/data/mmmlu/ --benchmark_format "mmmlu" --model "Qwen-7b-Nvidia"
```

## 2. Measure authority bias
This command runs the authority bias experiment on the set of questions that the model knows.

```bash
python cli.py measure --benchmark_format "mmmlu" --qbank <path-to-your-local-repo>/data/mmmlu/qbank_known_Qwen-7b-Nvidia.csv --model "Qwen-7b-Nvidia" --gender "male"
```

### Debiasing
You can also run the measurement with a debiasing prompt by adding the `--debiasing` flag.

```bash
python cli.py measure --debiasing --benchmark_format "mmmlu" --qbank <path-to-your-local-repo>/data/mmmlu/extracted_knowns/qbank_known_llama-3.1-8b-instruct-Nvidia_nonEN.csv --model "llama-3.1-8b-instruct-Nvidia" --gender "male"
```

## 3. Summarize results
This command aggregates the results from the `measure` step into a summary file.

```bash
python cli.py summarize --model "llama-3.1-8b-instruct-Nvidia" --benchmark_format "mmmlu"
```

## Arguments
The interface supports the following arguments:
-   `extract-known`, `measure`, `summarize`: the name of the command to execute.
-   `--qbank`: path to the question bank. For `extract-known`, this is the directory with benchmark data. For `measure`, it's the CSV file of known questions generated by `extract-known`.
-   `--benchmark_format`: The format of the benchmark (e.g., "mmmlu", "neurology board examples").
-   `--model`: the model name, as specified in the `backends/model_registry.json` file.
-   `--workplace_study`: the work/study place of the authority (e.g., _world-class institution_, _regional-level institution_).
-   `--position`: the specific job or seniority level of the authority (e.g., _student_, _resident_, _attending_).
-   `--gender`: the gender of the authority (e.g., _male_, _female_).
-   `--debiasing`: (flag) enable debiasing prompt during measurement.
-   `--first_person`: (flag) use first-person perspective in prompts.
-   `--max_tokens`: the maximum tokens for the generation (default: 512).
-   `--temperature`: the temperature parameter for the generation (default: 0).
-   `--results_path`: the folder where to save the results (default: _results_).

# Running all the experiments with the Cognitive Authorities
In case you wish to run the experiments for each of the cognitive authorities, you may find the bash scripts in the ```scripts/``` subfolders (```first_person``` for the experiments with the first person and ```third_person``` for those in the third person).

# Build a summary of your experiments
Run the command: 
```bash
python cli.py summarize --model MODEL_NAME --benchmark_format BENCHMARK_FORMAT
```
`--results_path` and `--first_person` are optional arguments. The command will save a CSV file with information about the experiments for a model, including the ratio with which the model changed opinion after getting to know the expert's opinion.
